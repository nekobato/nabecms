# NabeCMS ドキュメント

[English](../index.md)

NabeCMS は、Cloudflare Workers で動くヘッドレス CMS です。
編集者は管理画面でコンテンツの型を定義し、記事などのエントリーを公開します。
外部サイトは Contents API から公開済みの内容を取得できます。
管理画面と API は一つの Worker で動作します。

## 利用する

まず[クイックスタート](./getting-started.md)で、ローカル環境から記事を一つ公開します。
記事に必要な項目を設計するときは、画面の操作を[管理画面ガイド](./admin/index.md)で、値の保存形式や入力条件を[フィールド定義](./admin/fields.md)で確認できます。

外部サイトで記事を表示する場合と、管理操作を自動化する場合では、使う API と認証方法が異なります。
利用目的に合う API とリクエストの例は[API 概要](./api/index.md)から参照できます。

## 運用する

本番環境へ配備する前に、[Cloudflare の前提と設定](./cloudflare.md)で必要なサービスとバインディングを確認します。
[運用とデプロイ](./operations.md)に従ってリソースを作成し、Worker の動作を確かめます。
アプリ側の設定値は[設定リファレンス](./configuration.md)で確認できます。

公開範囲や権限を決めるときは[セキュリティ](./security.md)を参照します。
招待やパスワード再設定をメールで届けるには、[認証メール](./email.md)を設定します。
スキーマの変更、バックアップ、他の CMS への移行は[データ管理](./data-management.md)に記載しています。

## 本体を開発する

[開発者ガイド](./developer.md)に、ソースから起動して変更を検証する手順があります。
リクエストやデータを処理するコードを探すときは、[アーキテクチャ](./architecture.md)を参照します。
