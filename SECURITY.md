# Security Policy

## Supported Versions

Security fixes are provided for the latest release.

## Reporting a Vulnerability

Please do not open a public issue for security reports.

- Use GitHub Security Advisories to report vulnerabilities.
- If private vulnerability reporting is unavailable, email
  [nekobato@gmail.com](mailto:nekobato@gmail.com) with the subject
  `[NabeCMS Security]`. Do not include secrets or personal data that are not
  required to reproduce the issue.

## Operational Security Notes

- See the [security guide](docs/security.md) for runtime configuration guidance.
