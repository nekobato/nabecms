# create-nabecms

[日本語](https://github.com/nekobato/nabecms/blob/main/packages/create-nabecms/README.ja.md)

An initializer that creates a NabeCMS app for Cloudflare Workers.

```bash
npm create nabecms@next my-cms
```

`next` points to the latest Alpha release.
To select a specific version, run a command such as `npm create nabecms@0.1.0-alpha.1 my-cms`.
The initializer pins the runtime and CLI to its own version and runs `pnpm install` after creating the app.

For prerequisites and first startup, see the [Quick Start](https://github.com/nekobato/nabecms/blob/main/docs/getting-started.md).
For production configuration, see [operations and deployment](https://github.com/nekobato/nabecms/blob/main/docs/operations.md).
Compatibility changes and data migration instructions for Alpha releases are published in [GitHub Releases](https://github.com/nekobato/nabecms/releases).
