## Run locally

Copy `.dev.vars.example` and replace each secret with a different random value before starting the app.
For prerequisites and secret configuration, see the [Quick Start](https://github.com/nekobato/nabecms/blob/main/docs/getting-started.md).

```bash
cp .dev.vars.example .dev.vars
# Set the secrets in .dev.vars
pnpm nabecms:migrate --local
pnpm nabecms:doctor
pnpm typecheck
pnpm dev
```

Open the Admin UI at `http://localhost:8787/admin/`.
