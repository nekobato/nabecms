# @nekobato/nabecms-cli

[日本語](https://github.com/nekobato/nabecms/blob/main/packages/nabecms-cli/README.ja.md)

The Node.js CLI checks NabeCMS host app configuration, applies D1 migrations, and generates the runtime migration bundle.

Use it through the package scripts generated by `create-nabecms`.
For prerequisites and setup, see the [NabeCMS Quick Start](https://github.com/nekobato/nabecms/blob/main/docs/getting-started.md).

## Commands

```bash
pnpm nabecms:doctor
pnpm nabecms:migrate --local
pnpm nabecms:bundle-migrations
```

- `doctor` validates Wrangler bindings, local environment variables, and `nabecms.config.ts`.
- `migrate` applies D1 migrations through Wrangler and updates the runtime migration bundle. For production, pass `--remote --env production`.
- `bundle-migrations` regenerates the runtime migration bundle from `migrations/`.

Use `@nekobato/nabecms` as the Worker runtime dependency. The CLI runs in Node.js outside the Worker bundle.
