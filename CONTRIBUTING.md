# Contributing

Thank you for your interest in contributing. This guide describes the basic workflow.

## How to contribute

1. Fork the repository and create a feature branch.
2. Make your changes with clear commits.
3. Run tests and linting before opening a PR.
4. Open a pull request with a clear description.

## Development and validation

See the [Developer Guide](docs/developer.md) for setup, repository structure, and validation commands.
Update the relevant documentation when changing behavior.
Do not commit credentials or secret keys.
